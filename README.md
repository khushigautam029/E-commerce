# MERN E-Commerce Website

## Overview

A full-stack e-commerce platform developed using MERN stack.

## Features

- User Authentication
- Product Listing
- Add to Cart
- Checkout
- Admin Dashboard
- Order Management

## Tech Stack

Frontend:
- React

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## Installation

Frontend

npm install
npm start

Backend

npm install
npm run dev
